# Telegram Haber Botu

Haber sitelerinden, herkese açık Telegram kanallarından, Google Trends ve Twitter gündeminden
yeni içerikleri alıp bir Telegram kanalına otomatik gönderen sunucusuz bot.
GitHub Actions her 10 dakikada bir çalıştırır (kendini yenileyen uzun çalışma); sunucu, veritabanı ve ücret yoktur.

Kurulum, ayarlar ve sorun giderme: [telegram-haber/README.md](telegram-haber/README.md)
